# My First Go Program

## Versions

### v1 - Calculator
Simple calculator with logs support.
```bash
git checkout b933c0535eee8c90c8385862169e1d2ea5987987
```

### v2 - Services Manager
Manage Services with maps.
```bash
git checkout 58fc519cbc7920813f99464bcabf02fc8b544db6
```

### v3 — Mini Backend
Mini backend system with:
- User registration
- Login system
- Posts management
- Basic relations between users and posts

```bash
git checkout main
```

## Requirements
- [Go](https://go.dev/dl/) installed on your machine

## Run
```bash
git clone https://github.com/marvents/first-go-program.git
cd first-go-program
go run .
```
